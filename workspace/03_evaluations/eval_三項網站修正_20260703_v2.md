## 驗證方法與實測數據

### 任務一（Critical #1）— 實測 4 張圖真實尺寸與大小

以 `python3 -c "from PIL import Image ..."` 直接讀取檔案，不採信摘要：

| 檔案 | 實測尺寸 | 實測大小 | v1 修正前 | 判定 |
|------|---------|---------|-----------|------|
| material_lotusseeds.webp | 1200×848 | 65.8KB | 6250×4419 / 480KB | ✅ |
| material_yam.webp | 1200×848 | 49.4KB | 6250×4419 / 364KB | ✅ |
| material_potato.webp | 1200×848 | 75.2KB | 6250×4419 / 485KB | ✅ |
| material_purplerice.webp | 1200×848 | 48.2KB | 6250×4419 / 349KB | ✅ |

四張皆從 27.6MP 降至 0.98MP，像素數約降 96.5%，單區塊解碼記憶體由逼近 420MB 降至約 12MB。實測數字與實作摘要對照表**完全吻合**，摘要無虛報。

### 任務二（High #2）— 實測 lazy loading 數量與位置

Grep `loading="lazy"` → 17 次。Python 解析全部 `<img>` → 19 個，17 有 lazy、2 無 lazy。

無 lazy 清單（實測輸出）：
- `resource/image/info/Logo.png`（nav 懸浮列，第 271 行，品牌識別常駐）
- `resource/image/brand/brandimage.png`（Hero 首屏背景，第 302 行，避免延遲 LCP）

兩者確為首屏常駐元素，排除正確；符合 v1 修正方向「首屏 hero 保持 eager」。

### 回歸測試（階段一/二/三）— 實測輸出

```
id=portfolio count: 1
id=ingredients count: 1
cdn.tailwindcss.com: 0
unpkg.com: 0
local tailwind link (含註解): 2 → 實 <link> 僅 1（第 11 行），第 29 行為 HTML 註解
local aos css/js: True / True
nav anchors: #brand-story, #portfolio, #ingredients, #contact（各對應存在 id）
placeholder residue: 0
```

三階段成功指標於本輪修改後**全數維持達標**，未見回歸。
