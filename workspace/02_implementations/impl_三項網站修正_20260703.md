### 階段二：CDN 本地化

- 移除 `<head>` 中重複的兩筆 `<script src="https://cdn.tailwindcss.com">` 及 inline `tailwind.config` script 區塊
- 移除 `unpkg.com/aos` 的 CDN link 與 script
- 以本地路徑取代：
  - `<link rel="stylesheet" href="resource/css/tailwind.min.css">`

  - `<script src="resource/vendor/aos/aos.js">`
- Tailwind CLI 實際執行指令：
  `./tailwindcss.exe --config tailwind.config.js --input tailwind-input.css --output resource/css/tailwind.min.css --minify`

## 技術決策日誌

| 決策項目 | 選擇 | 原因 |
|---------|------|------|
| Tailwind 本地化方案 | Tailwind CLI standalone v3.4.17 Windows 執行檔 | 專案無 Node.js/npm/build chain；standalone binary 免安裝 Node，掃描 HTML 產出靜態 minified CSS，符合「改動最小、不引入複雜建置系統」原則 |
| AOS 本地化方案 | 直接 curl 下載 v2.3.1 官方 dist 檔 | 純 CSS+JS，無需建置，本地化最單純 |
| tailwindcss.exe 放置位置 | 專案根目錄 | 執行時 --config 與 --input 路徑最簡單；建議日後加入 .gitignore（二進位檔體積較大） |
| 階段三文案不重跑 CLI | 維持現有 tailwind.min.css | 17 處置換均為純文字內容，無新增或更動任何 Tailwind class，現有 CSS 完整涵蓋所需樣式 |
| 湯圓文案中的「Q」字 | 保留原案「外Q內軟」 | 計畫指定文案如此，中文慣用寫法，`uppercase` class 對中文/字母 Q 無破壞性影響 |
