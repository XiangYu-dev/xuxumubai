### 階段三：Hero 載入穩健性 + 無障礙

**`<video>` 補 poster：**
- 加入 `poster='resource/image/brand/brandimage.png'`，影片載入前不再出現黑畫面

**漢堡選單按鈕：**
- `<div class="mobile-menu-btn">` 改為語意正確的 `<button type="button">`
- 加入 `aria-label="開啟導覽選單"`、`aria-expanded="false"`、`aria-controls="mobileDropdown"`
- 三個裝飾性 `<span>` 加 `aria-hidden="true"`

**JavaScript Hero 顯示邏輯重構（核心改動）：**
- 舊邏輯：導覽列與 Hero 文字完全依賴 `heroVideo.ended` 事件，影片播完才顯示
- 新邏輯：
  - `revealHeroContent()` 統一函式，負責顯示 navbar、herotext-range、heroTitle、heroSubtitle
  - `heroFallbackTimer`：頁面載入後 **1.5 秒**必定執行 `revealHeroContent()`，不論影片狀態
  - `heroVideo.play()` 成功（`play` 事件）：立即 `clearTimeout` 並呼叫 `revealHeroContent()`，不再等影片播完
  - `heroVideo.play()` 被瀏覽器阻擋（Promise rejected）：立即顯示 `heroBgimage` + 呼叫 `revealHeroContent()`
  - `heroVideo.ended`：僅負責切換背景（影片淡出→顯示靜態圖），不再控制導覽列顯示
  - `heroVideo.error`：fallback 顯示靜態圖與內容
- `aria-expanded` 與 `aria-label` 隨漢堡選單開合即時更新（click / mouseleave / 外部點擊三個事件均同步）

**CSS `prefers-reduced-motion`：**
- 新增 `@media (prefers-reduced-motion: reduce)` 區塊
- 所有 animation、transition 縮短至 0.01ms（等同停用）
- `#heroVideo { display: none }` + `#heroBgimage { opacity: 1 }`：減少動效偏好者直接跳過影片，顯示靜態圖
