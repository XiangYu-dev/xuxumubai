## 需求摘要
針對「煦煦木白」甜品品牌形象官網進行三項修正：修復兩個 section 重複的 `id="portfolio"` 造成的錨點失效問題、將 Tailwind/AOS 的 CDN 依賴改為對此無建置專案最務實的本地化方案、以及以符合品牌調性的暫定草稿文案填補多處佔位符。本計畫僅規劃 index.html 單一檔案的內容調整，不引入框架或複雜建置系統。

## 執行順序與理由
建議執行順序：**階段一（id 重複修正）→ 階段二（CDN 優化）→ 階段三（文案置換）**。
- id 重複是**功能性缺陷**（錨點定位錯誤），且改動範圍最小、最獨立，優先修復可先讓導覽功能恢復正確。
- CDN 優化牽涉 `<head>` 結構與外部檔案下載，屬結構層調整，與文案互不干擾，排第二。
- 文案置換為內容層工作、逐處替換、量最大但風險最低，且為「暫定草稿待客戶確認」性質，放最後可避免在結構未定前反覆搬動文字。

### 階段二：優化 CDN 依賴（Tailwind 本地化 + AOS 本地化）
- **採用方案（務實優先，改動最小）：**
  - **Tailwind → 採用 Tailwind CLI standalone 執行檔產生純 CSS 檔案**。理由：此專案無 Node.js/npm、無 build chain，standalone 執行檔（單一 binary，免安裝 Node）可掃描 index.html 的 class 並輸出一份 minified 純 CSS，最貼近「不引入複雜建置系統」的要求，同時解決 Tailwind 官方不建議 CDN 用於 production 的問題。產出的 `resource/css/tailw.css`（或 `tailwind.min.css`）為靜態檔，可直接 commit 進 Git，日後若 class 有增減再重跑一次 CLI 即可。
  - **AOS → 直接下載 `aos.css` 與 `aos.js`（v2.3.1）存為本地檔**。理由：AOS 為純 CSS+JS 函式庫，無需建置，本地化最單純、風險最低。
- **取捨說明（寫入計畫供決策留痕）：**
  - 不採「純 CDN 保持現狀」：Tailwind 官方明確不建議 production 使用 CDN，且有外部服務可用性風險。

  - standalone CLI 為折衷最佳解：一次性產出靜態 CSS，無常駐建置流程、無 CI/CD 需求，符合現況。
  - **保留退路**：若團隊短期內不便執行 CLI，可先只完成 AOS 本地化 + 移除重複的 Tailwind CDN（見下），Tailwind 本地化留待後續；此為降級方案，須在交付說明中標註。

| 風險項目 | 影響程度 | 對策 |
|--------|--------|------|
| Tailwind CLI 未涵蓋動態/字串拼接產生的 class，導致樣式遺失 | 中 | 本專案 class 皆為靜態寫在 HTML，風險低；掃描後於瀏覽器逐區塊目視比對，發現遺失則檢查 CLI content 掃描路徑設定 |

| 文案新增 class 後未重跑 Tailwind CLI，樣式缺失 | 中 | 遵循「先文案定稿、最後統一重跑 CLI」流程（見注意事項）；本次文案多為純文字置換 |
| 改 id 後遺漏更新對應 nav 連結，錨點失效 | 低 | 階段一驗收標準逐項核對 nav 與 section id 對應 |
