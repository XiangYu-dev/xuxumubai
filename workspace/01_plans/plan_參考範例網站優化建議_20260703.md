# 執行計畫：參考範例網站（怡満分 yimanfen.cn）優化建議

**建立日期：** 2026-07-03
**版本：** v1.0
**狀態：** 階段一～三（A 類）已完成（驗收通過 eval_參考範例網站優化建議_20260703_v1）；階段四～六（B 類）待客戶確認，整份計畫尚未全數完成

---

## 需求摘要

客戶提供競品/參考範例網站 **怡満分（yimanfen.cn）**——一個 2024 年創立於中國大陸、主打「新中式糖水」的甜品品牌官網，希望據此優化「煦煦木白」形象官網。本計畫先分析範例網站的視覺、內容架構與敘事手法，再對比煦煦木白現況（純靜態單頁 `index.html`），找出可借鏡與**不宜照搬**之處，最後以「效益／成本」排序給出可執行的優化清單。

> 重要前提：`yimanfen.cn` 為 JS 前端渲染的 SPA，直接抓取原始 HTML 僅能取得品牌名，無法取得完整 DOM。本計畫的範例網站分析，是以「首頁品牌名 + 多家餐飲/商業媒體對該品牌的報導」交叉佐證而成（來源見文末）。因此對「視覺/動效細節」的描述屬**間接推論**，凡涉及具體視覺決策者，一律標註為「需與客戶確認的設計決策」。

## 一、範例網站（怡満分）分析

### 1. 品牌定位與受眾
- 定位：「時尚、健康、年輕」的都市消費選擇；訴求「回歸本源、追求純粹」，融合法式甜點精緻、日式和菓子禪意、新中式甜品韻味。
- 產品哲學：「鮮果、鮮奶、鮮作」，強調嚴選原料（建寧白蓮、特 A 級桃膠、悅鮮活鮮奶）與手工現煮。
- 明星品項：芒果雪糯、滿分大滿貫；季節限定（夏「植物能量」、秋「梨想」）、聯名（滿分薯薯）。客單約人民幣 20–30 元。
- 經營模式：首創「零售化輕座席」門店，**易拉罐外帶為主**、少量座位；截至 2025/11 全國約 60 家、跨城市商圈；主打**加盟擴張**。

### 2. 可推論的視覺與內容手法（間接資料）
- 空間/視覺調性：清新雅致、柔和燈光與綠植、國際化輕奢質感——與煦煦木白「東方生活美學、質樸詩意」方向相近但更「年輕、零售感」。
- 產品敘事：強調「原料溯源 + 工藝（現煮）+ 季節限定」，以明確**產品命名 + 定價 + 系列化（夏/秋限定、聯名）**建立記憶點與復購。
- 商業入口：以門店擴張與加盟為核心，官網很可能承載**加盟招商**與**門店據點**導流。

### 3. 明確「不宜照搬」之處（品牌/市場/法規差異）
| 範例網站特徵 | 為何不宜直接照搬到煦煦木白 |
|---|---|
| 加盟招商為核心 CTA | 煦煦木白目前為形象官網、台北/板橋 2 店，尚無加盟階段，貿然放招商會稀釋品牌調性。**需客戶確認是否有加盟規劃**。 |
| 標榜療效/養生功效字眼 | 台灣《食品安全衛生管理法》對食品宣稱有嚴格規範，不得宣稱醫療效能。文案須避免「養生、療效、調理身體」等越界用語。 |
| 大陸社群導購（微信/小程序/大眾點評） | 受眾與平台不同。煦煦木白應對應台灣生態：**LINE 官方帳號、Instagram、Google Maps、外送平台（UberEats/foodpanda）**，不可照搬微信體系。 |
| 「年輕零售感 / 輕奢」視覺語彙 | 煦煦木白現況走「詩意、留白、襯線體、東方美學」，兩者調性不同。是否要往更年輕/零售感靠攏屬品牌決策，**不可預設客戶接受**。 |
| 易拉罐外帶產品線 | 屬產品與供應鏈決策，非官網優化範疇，本計畫不納入。 |

## 二、煦煦木白官網現況盤點（index.html）

**技術現況：** 純靜態單頁；Tailwind + AOS 已本地化；Google Fonts 仍走 CDN；已做縮圖 + lazy loading。
**結構：** 導覽（品牌故事 / 精選甜品 / 嚴選食材 / 門店資訊）＋ Hero 影片 → 品牌故事 → 經典產品介紹 → 精選甜品（6）→ 嚴選食材（6）→ Footer（門店 + LINE QR + IG + FB）。

**盤點發現的具體缺口／問題（客觀，非設計決策）：**
1. **SEO / 分享缺失**：`<head>` 無 `<meta name="description">`、無 Open Graph / Twitter Card、無 favicon、無結構化資料（JSON-LD）。社群分享時無縮圖與描述。
2. **無障礙與語意**：多個裝飾用 `<span>` 包 `<img>`、部分 `alt` 空泛；導覽漢堡鈕缺 `aria-label`/`aria-expanded`；`<video>` 無 `poster`（影片載入前為黑畫面）。
3. **產品區文案殘留佔位/矛盾**：第 2、3 產品區皆標「夏日系列」且共用同一張圖 `brandimage5.PNG`（重複），標題「四時鮮飲」卻歸在「夏日系列」語意衝突。
4. **導購/CTA 幾乎缺席**：全站無任何行動呼籲（如「查看菜單」「LINE 訂位」「Google 地圖導航」「外送平台」）。門店地址純文字、無地圖連結。
5. **Footer FB 連結為空**（`href=""`）；LINE 僅 QR、無點擊連結（手機掃不到自己畫面上的 QR）。
6. **Hero 敘事對桌機依賴影片**：影片播完才顯示導覽與文字（`navbar` 初始 `opacity:0`）——若影片載入慢或自動播放被瀏覽器阻擋，導覽會遲遲不出現，體驗風險高。
7. **季節/產品系列化不足**：範例網站以「季節限定 + 系列」製造記憶點，煦煦木白目前 6 款甜品為平鋪、無系列敘事與價格/菜單資訊。

## 三、優化建議（依「效益／成本」排序）

分類：
- **A 類（純技術實作，可直接交 Generator）**——不改變視覺方向，屬修正/補強。
- **B 類（需與客戶確認的設計/內容決策）**——涉及品牌調性、版面新增、內容取向，確認後才實作。

## 執行階段

### 階段一：SEO 與分享性補強（高效益 / 低成本｜A 類）  ✅ 已完成（v1 驗收通過 2026-07-03）
- **任務清單：**
  - [x] `<head>` 補 `<meta name="description">`（品牌一句話介紹，含關鍵字：東方甜品/糖水/台北/信義）
  - [x] 補 Open Graph（og:title/description/image/url/type）與 Twitter Card
  - [x] 加入 favicon（可用現有 Logo.png 產出 .ico / 多尺寸）
  - [x] 加入 LocalBusiness / Bakery 類型 JSON-LD 結構化資料（店名、地址、營業時間、社群連結）
  - [x] `<html lang>` 確認為 `zh-TW`（現況正確，僅複查）
- **依賴前提：** 需 1 張 og 分享圖（可沿用 brandimage.png，或請客戶提供）

- **驗收標準：** 用 FB 分享偵錯工具 / Google Rich Results Test 驗證 OG 與 JSON-LD 無錯誤；社群貼連結出現正確標題、描述、縮圖。

### 階段二：現有內容錯誤與連結修正（高效益 / 低成本｜A 類）  ✅ 已完成（v1 驗收通過 2026-07-03；FB/LINE/板橋地址/OG網域 留佔位符待客戶提供）
- **任務清單：**
  - [x] 修正「經典產品介紹」第 2、3 區重複使用 `brandimage5.PNG`——替換為不同圖或改版面（**若需新圖，該子項轉為需客戶提供素材**）
  - [x] 修正「四時鮮飲」歸類於「夏日系列」的語意衝突（改標籤或改文案）
  - [x] 補齊 Footer FB `href`（**需客戶提供 FB 粉專網址**）；若無 FB 則移除該圖示避免死連結
  - [x] 門店地址加上 Google Maps 導航連結（`https://maps.google.com/?q=地址`）
  - [x] 檢查全站 `<img alt>`，補上具描述性的替代文字
- **依賴前提：** FB 網址、可能的替換圖片需客戶提供
- **預估工作量：** 小
- **驗收標準：** 無空連結 / 死連結；地址可點擊開啟地圖；產品區不再有重複圖與語意矛盾；所有圖片皆有有意義 alt。

### 階段三：Hero 與載入穩健性 + 無障礙（中效益 / 低成本｜A 類）  ✅ 已完成（v1 驗收通過 2026-07-03）
- **任務清單：**
  - [x] `<video>` 加 `poster`（影片首幀圖），避免載入前黑畫面
  - [x] 導覽列不再「等影片播完才顯示」：改為載入即顯示（或設定 fallback timer / 監聽 `play()` 被拒時直接顯示導覽與文字）
  - [x] 漢堡選單鈕加 `aria-label`、`aria-expanded` 並隨開合切換
  - [x] 為 `prefers-reduced-motion` 使用者降低/關閉自動動效（尊重系統偏好）
- **依賴前提：** poster 圖（可由影片截圖產生）
- **預估工作量：** 小～中
- **驗收標準：** 停用/延遲影片時導覽與主視覺仍在合理時間內出現；Lighthouse Accessibility 分數較現況提升；行動裝置實測不再長時間黑屏。

- **任務清單：**

  - [ ] 評估是否加入外送平台入口（UberEats / foodpanda）— **需客戶確認是否上架**
  - [ ] 評估頁尾或浮動「回到頂部 / 快速聯繫」按鈕
- **依賴前提：** 客戶提供 LINE 官方帳號 ID、外送平台連結、是否開放訂位
- **預估工作量：** 中
- **驗收標準：** **需客戶確認 CTA 方案後才進入 Generator 實作**；實作後所有 CTA 連結有效、行動裝置點擊區夠大（≥44px）、有 hover/焦點狀態。

### 階段五：產品系列化與季節敘事（中效益 / 中成本｜B 類，需客戶確認）
> **需與客戶確認的設計決策**：是否要引入「季節限定 / 系列」敘事、是否公開品項價格或菜單。此為借鏡範例網站「系列化製造記憶點」的作法，但**須符合台灣食品標示與不誇大宣稱規範**（避免養生/療效字眼）。
- **任務清單：**
  - [ ] 規劃「四時甜品」系列敘事（春/夏/秋/冬）取代現有平鋪 — **需客戶確認方向與文案**

  - [ ] 評估是否加入簡易菜單或價格區（**是否公開價格為客戶商業決策**）
  - [ ] 文案合規檢查：移除任何醫療/療效/養生功效宣稱
- **依賴前提：** 客戶確認產品系列策略與正式文案（現況文案為暫定草稿）
- **預估工作量：** 中
- **驗收標準：** **需客戶確認內容與合規後才進入 Generator**；上線文案經食安宣稱自檢清單通過。

### 階段六：整體視覺風格是否向範例靠攏（低急迫 / 高成本｜B 類，需客戶確認）
> **需與客戶確認的設計決策，且本計畫「不建議預設採用」**：範例網站偏「年輕、輕奢、零售感」，煦煦木白現走「詩意、留白、東方襯線美學」。兩者是不同品牌路線，**不應為了像範例而改變既有調性**。
- **任務清單：**
  - [ ] 與客戶釐清：品牌是否要年輕化/零售化？（若否，本階段擱置）
  - [ ] 若要調整：先出配色/字體/版面提案（Design Proposal），再談實作
- **依賴前提：** 明確的品牌方向決策
- **預估工作量：** 大
- **驗收標準：** **需客戶書面確認品牌方向後**才展開；未確認前不動現有視覺系統。

## 技術風險與對策

| 風險項目 | 影響程度 | 對策 |
|---|---|---|
| 範例網站為 SPA，視覺分析屬間接推論，可能與實際細節有落差 | 中 | 涉及視覺者全標為「需客戶確認」；必要時請客戶提供範例網站截圖再細化 |
| 全盤模仿導致品牌調性稀釋（受眾/市場/法規不同） | 高 | 明確區分「可借鏡（結構/敘事手法）」與「不宜照搬（加盟、療效宣稱、微信導購、輕奢視覺）」 |
| 食品宣稱越界違反台灣食安法 | 高 | 階段五納入合規自檢；禁用醫療/療效/養生功效字眼 |
| 客戶素材（FB 網址、替換圖、LINE ID、外送連結）未到位 | 中 | 各階段標註依賴；素材未到者，Generator 先做結構、以佔位待補，不硬編死連結 |
| Hero 改動影響現有影片體驗 | 低 | 保留影片，僅加 poster 與 fallback，不移除既有動效 |
| Google Fonts 仍走 CDN，與先前「CDN 本地化」方向不一致 | 低 | 可列為後續獨立優化（非本計畫核心），或於階段一順帶提出本地化建議 |

## 成功指標
- SEO：社群分享出現正確標題/描述/縮圖；Rich Results Test 對 JSON-LD 無錯誤。
- 品質：Lighthouse SEO 與 Accessibility 分數較現況提升（目標各 ≥ 90）。
- 正確性：全站 0 死連結、0 重複佔位圖、0 語意矛盾文案。
- 導購（若客戶採納階段四）：主要 CTA 於首屏可見且行動裝置可點擊。
- 合規：文案通過食安宣稱自檢清單，無療效/養生宣稱。

## Generator 注意事項
1. **先做 A 類（階段一～三）**——不涉及品牌決策，可直接實作，效益高、風險低。
2. **B 類（階段四～六）一律等客戶確認後再動工**，各該階段驗收標準已註明「需客戶確認後才能進入 Generator 實作」。
3. 缺素材（FB 網址、替換圖、LINE ID、外送連結、og 圖、poster）時，**以佔位結構待補，不得硬編無效連結或編造資訊**。
4. 修改僅限本專案 `index.html` 及 `resource/` 內資源；沿用既有 Tailwind 色票（brand-bg/brand-text/brand-gold/brand-accent）與 `:root` 變數，勿引入新設計系統。
5. 文案現況為「暫定草稿」，正式文案以客戶確認版為準；改文案時務必做食安宣稱合規檢查。
6. 範例網站的加盟招商、易拉罐產品線、微信/大眾點評導購**明確排除**，勿加入。
